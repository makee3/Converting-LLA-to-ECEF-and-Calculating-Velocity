Script transforms geospatial data from LLA to ECEF and calculates velocity of an object.

1. Add both the script and data file to the same folder.
2. Run 'python LLA_to_ECEF_conversion.py (integer between 1532332859 and
1532335359)'
3. Output will give velocity vectors for X, Y, Z in units of m·s⁻¹ at the requested time.
